# benchmarks/

The reproducible measurement harnesses behind NeoRAG's [findings](../docs/findings/README.md).
Every claim in the evidence layer is regenerated by one of these commands —
nothing is hand-asserted.

The harnesses live as runnable examples in `crates/examples/examples/` (Rust,
context/retrieval/reranking side) and `../neorag/scripts/` (Python lab, LLM
judging side). This directory is the catalog and the place for any
benchmark fixtures/configs that aren't code.

## Catalog

| Harness | Kind | Measures | Finding |
| ------- | ---- | -------- | ------- |
| `second_hop_retention` | Rust, hermetic | second-hop retention vs junk suppression by strategy (n=1327, CIs) | [SECOND_HOP_TAX](../docs/findings/SECOND_HOP_TAX.md) |
| `emit_reasoning_qa` + `score_reasoning_qa.py` | Rust + lab LLM | end-to-end answer quality: reasoning-preserving vs aggressive filtering | [REASONING_PRESERVATION](../docs/findings/REASONING_PRESERVATION.md) |
| `context_economics` | Rust, BGE | token-efficiency / gold-retention curves by strategy | [CONTEXT_ECONOMICS](../docs/findings/CONTEXT_ECONOMICS.md) |
| `distractor_answer_correlation` | Rust, NeoTrace | distractor/density ↔ answer quality on real LLM outputs | [CONTEXT_ECONOMICS](../docs/findings/CONTEXT_ECONOMICS.md) |
| `emit_qa_contexts` + `score_context_qa.py` | Rust + lab LLM | causal distractor degradation + filtering net effect | [DISTRACTOR_ROBUSTNESS](../docs/findings/DISTRACTOR_ROBUSTNESS.md) |
| `ce_escalation_economics` | Rust, ONNX | cross-encoder uniform vs selective vs oracle recall/cost | [RERANKING_LIMITS](../docs/findings/RERANKING_LIMITS.md) |
| `bge_dense_retrieval` | Rust, ONNX | controller economics on dense vs BM25 (action path) | [ADAPTIVE_CONTROLLER](../docs/findings/ADAPTIVE_CONTROLLER.md) |
| `bge_recalibration` | Rust, ONNX | threshold drift vs genuine substrate effect (sensing path) | [SUBSTRATE_COUPLING](../docs/findings/SUBSTRATE_COUPLING.md) |
| `real_embedding_bakeoff` | Rust, ONNX | BGE vs hashing recall + latency | [EMBEDDING_BAKEOFF](../docs/findings/EMBEDDING_BAKEOFF.md) |

ONNX harnesses need the `--features onnx` flag and a downloaded model (see
each finding's reproduce block). Hermetic harnesses (e.g.
`second_hop_retention`) run on the default offline build.

Workload data lives under `../neorag/data/` (HotpotQA, MuSiQue); cross-LLM
traces under `../neorag/exports/neotrace/`.
