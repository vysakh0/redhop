# Benchmarks

Every claim in the [findings](./findings.md) is regenerated by a reproducible
harness — nothing is hand-asserted. They live as runnable examples
(`crates/examples/`) and the Python lab; the catalog is in
[`benchmarks/`](https://github.com/redhop/redhop/tree/main/benchmarks).

## Strategy benchmark (hermetic)

```bash
cargo run -p redhop-examples --example bench_context_strategies --release
```

Drives all four strategies through the public `build_context` API across token
budgets and two HotpotQA populations, writing `results.json` + `SUMMARY.md` with
95% bootstrap CIs. No LLM, no embeddings — deterministic and CI-friendly.

Headline (multihop_gap, n=1327), second-hop retention across budgets:

```text
strategy              budget 250            budget 800
distractor_filtered   0.748 [0.724,0.770]   0.749 [0.724,0.772]   ← plateaus (filtered it out)
reasoning_preserving  0.827 [0.807,0.847]   0.833 [0.812,0.853]   ← lifts the plateau
raw_topk              0.963 [0.953,0.973]   1.000                 (keeps everything incl. junk)
```

`distractor_filtered`'s second-hop retention **plateaus at ~0.749 regardless of
budget** — it filtered the hop out, so a bigger budget can't bring it back.
`reasoning_preserving` lifts that to ~0.833 while keeping the output distractor
ratio low.

## End-to-end (LLM) benchmark

```bash
cargo run -p redhop-examples --example emit_reasoning_qa --release   # build contexts
python ../neorag/scripts/score_reasoning_qa.py --n 300               # lab: LLM + score + CIs
```

The Rust side builds contexts; the Python lab calls the generator and scores.
Captured output lives in
[`reports/reasoning_preserving_n300/`](https://github.com/redhop/redhop/tree/main/reports/reasoning_preserving_n300).

## Render any artifact

```bash
redhop report results.json --html report.html
```
